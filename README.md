# MatMap

Brazilian Jiu-Jitsu personal training log. Not a social network.

Record a class in seconds (voice, chips, or whiteboard photo). Build your system graph from what you actually drill and roll.

## Pages

Today · Log · Map · Cards · Me

## Stack

TanStack Start, Postgres / PGLite, Better Auth, Tailwind.

## Local

```bash
npm install
npm run dev
```

Auth is on. Sign in with email, then load the demo week from Today.

## Product rules

- Technique names display in English. Chinese / English aliases stay for voice and search.
- Visual language: koryu densho (washi, seigaiha, vermillion hanko).
- iOS-first. Recording a class is the fastest flow in the app.
- Free: chips, graph, cards. Pro: voice, AI diagrams, next-day review, PDF.
